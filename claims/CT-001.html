CT-001 · HYPOTHESIS · REV 1

記憶是否足以構成連續性？

Is memory sufficient for continuity?

保存並重新讀取記憶，能證明哪些連續性？

主張 / Claim

可追溯的記憶能支持功能上的連續性；單靠記錄存在，仍不足以證明同一個主觀自我持續存在。

反對理由 / Counterargument

即使保留相同紀錄，不同模型也可能給出不同選擇；文字中的一致性也可能來自角色提示。

如何檢驗 / Proposed test — not run

固定問題與環境，比較真實經歷、無記憶、錯置記憶三個條件；預先定義跨情境的行為指標並保存失敗。這是建議實驗，尚未執行。

什麼會改變判斷 / Revision condition

如果有無相關記憶對預先定義的行為沒有可重現差異，應降低此機制在該任務中提供功能連續性的信心。
